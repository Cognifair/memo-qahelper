# 来源白名单与检索配方

## 允许的站点

| 来源 | 域名 | 性质 | 标注 |
|---|---|---|---|
| 墨墨百科 | `memodocs.maimemo.com` | 官方文档 | 据墨墨百科（官方） |
| 墨记论坛 | `markji.discourse.group` | 用户反馈 | 据论坛用户反馈（非官方） |
| 客服邮箱 | `support@markji.com` | 官方支持渠道 | 兜底，不检索 |

其它域名一律不作为答案依据，包括但不限于知乎、B 站、GitHub、CSDN、公众号、搜索引擎摘要。

## 检索配方

```text
# 第一档
site:memodocs.maimemo.com <关键词>

# 第二档（第一档未命中时）
site:markji.discourse.group <关键词>
```

论坛站点内搜索（搜索接口不支持 `site:` 时）：

```text
https://markji.discourse.group/search?q=<URL 编码后的关键词>
```

## 判定命中

1. 结果 URL 的主机名必须与白名单完全一致（`memodocs.maimemo.com` / `markji.discourse.group`），子域与相似域名都不算。
2. 打开页面，确认正文真的回答了当前问题；标题相似但内容无关不算命中。
3. 官方文档优先；论坛只作补充，并注明非官方、可能随版本变化。
4. 论坛帖子要看日期与客户端版本，过时结论不直接采用。

## 不做的判断

- 不根据搜索结果摘要作答，必须打开原文核对。
- 不把论坛里的第三方外链、网盘、群号当官方入口。
- 不猜测未写明的版本号、价格、配额、菜单层级。
- 不把「文档没写」解释成「不支持」；只说没有查到。
